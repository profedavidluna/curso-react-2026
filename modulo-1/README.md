# Módulo I: Fundamentos Web Modernos

## Descripción

Este módulo cubre los fundamentos esenciales del desarrollo web moderno que todo desarrollador React empresarial debe dominar. Se abordan las tres tecnologías base de la web (HTML5, CSS y JavaScript) desde un enfoque profesional, junto con los patrones y arquitecturas modernas que impulsan las aplicaciones de nivel empresarial.

---

## Sesiones

| Tema | Descripción |
|------|-------------|

---

## Objetivos de Aprendizaje

Al finalizar este módulo, los estudiantes serán capaces de:

- ✅ Escribir HTML semántico y accesible siguiendo estándares WCAG 2.1
- ✅ Construir formularios robustos con validación nativa y avanzada
- ✅ Utilizar APIs web nativas del navegador (Storage, Drag & Drop, Geolocation)
- ✅ Comprender los Web Components y su integración con React 19
- ✅ Dominar Flexbox y CSS Grid para layouts modernos y responsivos
- ✅ Aplicar Variables CSS, Media Queries y animaciones profesionalmente
- ✅ Elegir la estrategia de estilos correcta (Sass, Less o CSS-in-JS)
- ✅ Escribir JavaScript moderno con ES6+ de forma idiomática
- ✅ Comprender las arquitecturas web modernas y cuándo aplicar cada una
